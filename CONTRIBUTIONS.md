# 작업물 선별 목록

## 선별 기준

- `source/`에는 해당 PR에서 추가한 파일 중, 마지막 개인 수정 커밋의 모든 줄이 정민규의 작성 이력으로 확인되는 파일을 보관했습니다.
- 원본 경로를 유지하고, 파일마다 추출 커밋과 관련 PR을 아래 표에 기록했습니다.
- `patches/`에는 공동 파일의 PR별 변경 내용을 보관했습니다. 패치에는 변경 위치를 보여주는 기존 코드 문맥이 포함됩니다.
- 팀원 인수인계 메모, 개발 보조 스크립트, 자동 생성된 DB 스냅샷은 선별에서 제외했습니다.
- PR #40의 DB 변경은 DB 담당자 커밋을 포함하므로 원본 PR에서 확인하도록 했습니다.
- 각 파일은 개인 작업 당시의 버전입니다. 이후 팀원이 개선한 운영 코드는 원본 저장소에서 확인할 수 있습니다.
